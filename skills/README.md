# Common Skills

This folder holds skills that I believe are general or common. 
Specific skills will still be in each individual repo. 

## Plan

The plan skill will output a plan markdown file for a feature request. 

The goal of the feature is to output a detailed step by step, test driven execution plan that can be executed by dumber or cheaper models. 

## Execute

The execute skill will ingest the plan markdown generated by the plan skill and implement the feature. 

The execute skill will test, lint, and document changes during execution and output a detailed summary of all the steps taken.
